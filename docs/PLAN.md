# Build plan

1. Create the monorepo, local Postgres setup, environment contract and Make targets.
2. Build FastAPI models, migration metadata, authentication and seeded original content.
3. Implement lesson, assessment, progress and skill APIs with server-side scoring.
4. Add grounded tutor retrieval and a swappable Gemini adapter with safe failures.
5. Add teacher-scoped dashboard and worksheet draft/approval APIs.
6. Build the responsive React learning experience, including Hindi strings and role-aware navigation.
7. Add deployment configuration, operational documentation and smoke checks.
8. Run backend and frontend checks; record only actual results.
